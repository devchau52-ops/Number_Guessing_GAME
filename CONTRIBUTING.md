# Contributing

Thank you for contributing to Number Guessing Game.

## Before you start

1. Fork the repository and create a branch with a clear name, such as `add-difficulty-levels`.
2. Keep changes focused on one improvement.
3. Build the project locally and make sure it completes without warnings.

## Pull requests

- Describe what changed and why.
- Include clear steps for manually testing behavior changes.
- Update the README when commands, features, or rules change.
- Keep the code formatted consistently with the existing style.

## Reporting issues

Include the operating system, compiler version, command used, expected result, and actual result.
