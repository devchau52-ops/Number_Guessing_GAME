# Code of Conduct

## Our pledge

We want participation in this project to be welcoming and respectful for everyone.

## Expected behavior

- Use respectful, inclusive language.
- Give and accept constructive feedback.
- Focus discussions on improving the project.

## Unacceptable behavior

Harassment, personal attacks, discrimination, and publishing someone else's private information without permission are not welcome.

## Reporting

If you experience or observe unacceptable behavior, report it to the repository maintainers privately. Reports will be reviewed fairly and handled with appropriate discretion.
